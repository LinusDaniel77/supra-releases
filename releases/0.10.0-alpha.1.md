# Supra 0.10.0-alpha.1 — Blender-native UI preview

This is a separate **Windows launcher/source kit requiring Blender 5.1.2**.
It is not a standalone installer or a feature-complete upgrade to Supra 0.9.1.
Stable 0.9.1 downloads and automatic updates are unchanged.

## Try the new UI

1. Install Blender 5.1.2 for Windows from the official Blender distribution.
2. Download `Supra-Native-0.10.0-alpha.1-Windows.zip` below.
3. Right-click the ZIP and choose **Extract All**. Do not launch inside the ZIP.
4. Open the extracted folder, then double-click **Start Supra.cmd**.
5. In the Blender viewport header, choose **Supra → Dimensioned Block**.

If your system blocks a launcher, do not disable security protections. Inspect
the included source and ask for help. The PowerShell alternative is documented
in the included README. The launcher uses an isolated Blender configuration.

## Included

- Actual Blender viewport, editor regions, Outliner, Properties, tools and keymap.
- Fresh Supra extension, with no application code imported from Supra 0.9.1.
- Millimeter-based block/cylinder blanks; dimension edits preserving placement
  and modifiers, with guards against overwriting manual/shared mesh edits.
- Mesh diagnostics and local design briefs; `.blend` save/reopen.
- Complete new extension/launcher source, tests, GPL license and upstream pin.
- `SHA256SUMS.txt` and a manifest to verify the downloadable ZIP.

## Not included / do not rely on this for production engineering

AI generation, exact B-rep/STEP CAD, mechanical sketch constraints, assembly mates,
the previous Supra services, updater integration and macOS packaging are not in
this preview. Cylinders are meshes, not exact cylindrical surfaces. Mesh checks
are not manufacturing, physics, tolerance or release certification. No cloud
calls, accounts, payments or telemetry are added. Keep backups of your work.

The 17 real-Blender smoke checks passed, including save/reopen and intentional
rejection of manual/shared mesh edits. Blender emits a small shutdown allocator
warning after this automated smoke run; this is documented and remains open.

The GPL-licensed new source is included in the ZIP. Blender's executable is **not**
redistributed here; obtain it from Blender's official distribution. This project
