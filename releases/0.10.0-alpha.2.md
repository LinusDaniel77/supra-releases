# Supra 0.10.0-alpha.2 — portable native engineering preview

## Download and open

Download **Supra-0.10.0-alpha.2-Windows-x64-Portable.zip**, extract the entire ZIP,
and open **Supra.exe**. Keep its runtime folder beside it. Windows x64 only.
No separate Blender installation, account, Python setup or internet connection is
required to use the workspace. Source archives are optional downloads for users
who want to inspect or rebuild the software, not extra runtime requirements.

## New in this preview

- Bundled, pinned, unmodified Blender 5.1.2 runtime with a quiet Supra GUI launcher.
- Independent per-user settings and local diagnostic logs, without changing the
  normal Blender installation/profile.
- Focused native workspaces and part, feature, inspection, project and brief panels.
- Live bevel, constant-pitch pattern, symmetry and mesh Boolean controls.
- Part numbers/project metadata saved with .blend projects; recorded mesh evidence.
- Dimension/unit checks, preservation of manual edits, and dependency-cycle refusal.

## Important limitations

This is a **mesh-modeling alpha**, not the full previous Supra CAD/AI product.
Exact B-rep/STEP CAD, mechanical sketch constraints, assembly mates, AI generation
and legacy Supra services are not connected. Mesh measurements are not physics,
tolerance, manufacturing, or safety approval. Material notes are metadata only.
Keep backups and do not rely on this alpha for safety-critical work.

This is an **unsigned portable folder**, not an installer. Do not disable Windows
security protections if blocked. Native Blender names/credits remain visible.
No new account, billing, telemetry or model-provider calls are added. Hosting
providers may process ordinary download connection logs.

29 real-runtime smoke checks and 9 packaging tests pass. Release packaging reruns
the bundled launcher's smoke suite. Native visual verification was interrupted
during development and clean-machine testing is incomplete. A small Blender
headless shutdown allocator warning (315 blocks, about 23 KB) remains documented.

This is a separate prerelease. It does not replace stable 0.9.1 or change the
existing updater manifests. Earlier alpha assets remain available.
